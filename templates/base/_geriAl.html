{% comment %} "Geri al" bildirimi (ürün raporu 12.7): onay penceresi yerine birkaç saniyelik alt bildirim — "aim listenden çıkarıldı · Geri al". Mobilde alt menünün üstünde, masaüstünde ekranın altında durur. Aynı anda tek bildirim görünür; yenisi gelince eskisi kapanır. JS API (layout.html'de her sayfaya bir kez eklenir): window.geriAl.goster(mesaj, geriAlFonksiyonu, secenekler) mesaj -> düz metin (HTML değil) geriAlFonksiyonu -> "Geri al"a basılınca çağrılır. null ise düğme çıkmaz. secenekler.sure -> ms, varsayılan 5000 secenekler.bitince-> bildirim geri alınmadan kapanınca (süre dolunca ya da yerine yenisi gelince) çağrılır. "Önce arayüzden kaldır, süre dolunca sunucuya yaz" düzeni için. döner: { kapat() } window.geriAl.bildir(mesaj) -> Geri al düğmesi olmayan kısa bildirim. Örnek: geriAl.goster('aim listenden çıkarıldı', function () { ekle(id); }); {% endcomment %}
